# MESH — BMS Campus Network

Next.js 15 + Supabase PWA for BMS students.

## Stack
- Next.js App Router
- Tailwind CSS v4
- Supabase Auth + Realtime
- Multi-color dopamine UI

## Deploy
Connect this repo to Vercel with **Root Directory** = repo root (not mesh-phase1).

```bash
npm i && npm run build
```
